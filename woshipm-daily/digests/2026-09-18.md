## 09 · 黑盒审计研究关注输出 token 膨胀：单次探针平均检出率 85.1%

论文定义 Provider-Side Token Inflation Attack，模拟供应商在查询、提示、表示或模型层让输出变长但大致保持任务效用。5 类攻击都把平均输出长度推到干净基线的 10.2 倍以上。作者利用“首次干预增幅大、进一步强化趋于饱和”的模式设计单次黑盒探针，在 4 个开源模型上平均检出率为 85.1%、误报率低于 2%；对 15 个真实 API 服务测试时，7 个出现与该假设一致的行为。

**产品经理视角：**按输出 token 计费的 AI 产品需要让客户核对输出长度、停止原因、模型与参数版本，并建立跨供应商的抽样基线和异常告警。审计信号应触发复测、合同核查和供应商沟通，而不是直接给出欺诈结论；产品侧还要防止自身提示和重试策略制造同样的长度异常。

**可写角度：**按 token 计费的 AI 服务怎样建立可复现的成本异常审计，而不把统计异常误判成供应商欺诈？

**核验边界：**arXiv v1 时间为 2026-09-17T13:28:06Z，即北京时间 21:28:06。这是未同行评审预印本；15 个真实 API 中的 7 个只表现出 PTIA-consistent behavior，摘要没有证明供应商主观操纵或排除所有正常原因。85.1% 与低于 2% 的结果来自 4 个开源模型和作者设置，实际服务需独立复验。
