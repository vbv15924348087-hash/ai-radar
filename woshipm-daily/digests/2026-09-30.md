## 02 · 腾讯云将下线 DeepSeek-V4-Flash 0731，只有符合条件的账户会自动迁移

编号：2026-09-30-02｜原文日期：2026-09-30｜24 小时内｜腾讯云官方公告

腾讯云公告称，TokenHub、智能体开发平台 ADP 和云开发 CloudBase 将于北京时间 10 月 31 日 00:00 下线 DeepSeek-V4-Flash 0731，并为符合条件的账户自动切换到届时平台可用的最新 DeepSeek 系列非原厂直供模型。后付费 API 用户须已对目标模型开启按量付费；使用企业版 Token Plan 调用旧型号的账户也符合条件。不满足条件的请求在下线后将失败。

**产品经理视角：**自动迁移并不等于无感升级。产品经理应提前盘点模型 ID、资格和计费开关，固定回归任务集验证新旧输出与时延，设置超时重试，并向用户解释目标模型可能变化、价格可能不同及无法自动切换的失败路径。

**可写角度：**AI 模型退役如何不让业务掉线：资格检查、自动迁移、效果回归、计费告知和失败回退五步法

**核验边界：**腾讯云公告列表与详情页显示发布时间为北京时间 2026-09-30 11:17:53，处于严格窗口。公告发布时平台最新版是 V4.1-Flash，但实际自动切换目标可能随之后的新版本变化；切换时可能有数秒请求超时，目标模型的效果和计费均可能不同。本条是腾讯云托管渠道的模型下线公告，并非 DeepSeek 官方发布新模型。

## 03 · Visual Studio 2026 更新 BYOM 预览：多模型接入新 Agent，旧模式需要迁移

编号：2026-09-30-03｜原文日期：2026-09-29｜24 小时内｜Microsoft Visual Studio Blog

Visual Studio 2026 的九月更新把 Bring Your Own Model（BYOM）预览接入新 Agent（Preview），在 Community、Professional、Enterprise 版本默认启用 BYOM。它支持 Microsoft Foundry、OpenAI、Anthropic 和 Ollama，其中 OpenAI 与 Ollama 可配置自定义端点；同次更新还把 NuGet Audit 漏洞警告连接到 Copilot Agent 修复流程，并让 Git Agent 从 PR 中提供可导航的评论和文件链接。

**产品经理视角：**多模型 Agent 的体验不能只停在模型选择器。团队需要明确不同模型能完成哪些工具动作、哪些能力降级，保留旧模式迁移提示，并将漏洞修复、代码审查等任务的输入、执行和最终人工复核连起来。

**可写角度：**多模型代码助手怎样维持一套可靠工作流：从 BYOM 兼容、能力提示到旧会话迁移

**核验边界：**官方页面时间为 2026-09-29T16:00:04Z，即北京时间 9 月 30 日 00:00:04，处于严格窗口。BYOM 和新 Agent 均是 Preview，不是所有模型都支持全部 Agent 能力；旧 Ask/Agent 模式不再支持 BYOM，原有 Ollama 模型需重新添加。NuGet 自动修复需登录 GitHub Copilot 并启用内置 NuGet MCP server。

[阅读原文](https://devblogs.microsoft.com/visualstudio/visual-studio-september-update-power-your-workflow-with-your-model/)

**可写角度：**企业 AI 部署如何把国家边界、单区驻留、吞吐和故障恢复变成可审核的模型路由策略？

**产品经理视角：**合同 Agent 不能只凭一次自然语言回答交付结果。产品经理可把字段置信度、第二模型异议、确定性规则、人工复核、原文定位和跨文档统计分层设计，再分别衡量误提取、漏提取、复核量与每份合格合同的处理成本。

**可写角度：**合同 Agent 怎样从能读 PDF 走向可验收：结构化提取、独立核验、确定性校验与人工复核
