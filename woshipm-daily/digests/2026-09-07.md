## 02 · Qwen Code 新预览版：给并行任务独立工作区，让后台 Agent 状态可见

编号：2026-09-07-02｜原文日期：2026-09-06｜24 小时内｜Qwen Code 官方 GitHub 发行记录及 PR

Qwen Code v0.23.1-preview.1 纳入可选的 Git worktree 隔离，让 daemon 管理的具名 Channel 任务使用独立工作区，避免多个任务直接改动同一份检出文件；关闭或重启后可恢复任务对应的会话与工作区。Web Shell 还为后台 Agent 增加运行标识，为前台 Agent 的折叠行显示耗时与当前工具提示。

**产品经理视角：**当一个 AI 产品允许用户同时交办多个任务，产品设计需要回答每项任务改了哪份文件、现在是否仍在执行，以及重启后能否回到原任务。独立工作区与明确状态可以分别降低任务间误改和用户误判，适合加入并行 Agent 产品的验收项。

**可写角度：**用户同时交给 AI 三项工作，产品经理该怎样设计任务隔离、状态展示和恢复流程？

**核验边界：**GitHub API 的 published_at 为 2026-09-06T13:18:54Z，即北京时间 9 月 6 日 21:18:54，属于本轮近 24 小时。该版本标记为 prerelease，不能写成稳定版全量开放。工作区隔离需要明确启用，适用 daemon 管理且支持该能力的 Channel；对应 PR 未完成真实外部通道 E2E 或 Windows/Linux 本地验证，自动合并改动、删除分支与进行中任务的崩溃恢复不在本次范围。本期未实测。

## 05 · Anthropic 预告 Enterprise Frontier Safeguards：监测活动数据可放在客户自己的云账户

Anthropic 宣布 EFS，计划让客户将用于滥用监测的活动数据存放在自己的云账户，采用客户控制的密钥、访问策略与审计日志；检测到的信号交由客户人员复核。服务将在今年秋季分批推出；Anthropic 不额外收取 EFS 费用，客户选择自有云存储时仍需承担云侧存储、读写和出站费用。

**可写角度：**企业 Agent 上线前，产品经理怎样把数据保留、监测与人工复核写成可执行需求。

**核验边界：**9 月 1 日公告，作为本周未收录补充；EFS 尚为秋季分批推广计划，不能表述为已全面上线。零数据保留指 Anthropic 侧的方案承诺，不等于客户侧不保存监测数据；具体资格和合同边界需按客户申请确认。与昨日 Fable 缓存价格条目是不同治理事件。

## 06 · 最高法发布 AI 纠纷审判意见：责任边界开始进入产品流程与证据设计

编号：2026-09-07-06｜原文日期：2026-09-07｜24 小时内｜最高人民法院官方发布

最高人民法院发布《关于依法审理涉人工智能纠纷案件的意见》，共 24 条，覆盖开发者、提供者与使用者责任，个人信息用于训练、侵权通知处置、AI 换脸拟声、产品缺陷、算法定价、自动驾驶、生成内容著作权、开源责任、数据权益和 AI 证据等问题。文件要求人民法院结合服务类型、训练数据来源、各方参与度和必要措施等因素认定责任。

**产品经理视角：**产品经理可以把司法责任转成可验收的产品要求：给用户清楚的同意与拒绝入口，保存内容来源和关键操作记录，建立权利人通知后的停止生成与处置流程，在高风险场景展示警示，并确保模型版本、训练数据来源、处置动作和证据链可追溯。

**可写角度：**AI 产品经理如何把司法责任写进需求：从同意、处置到证据留存的产品清单。

**核验边界：**原文页面显示 2026 年 9 月 7 日 19:22:29，属于本轮近 24 小时。这是最高人民法院发布的司法裁判规则文件，并非一部专门的人工智能法；具体案件仍需结合事实、服务形态和现行法律判断。本文仅提炼产品设计影响，不构成法律意见。

[阅读原文](https://www.court.gov.cn/zixun/xiangqing/511101.html)

> 生成式人工智能自动生成的内容侵害他人名誉权、隐私权等人格权益，经权利人通知，生成式人工智能服务提供者未及时采取停止生成侵权内容等必要措施的，应当对造成的损害依法承担侵权责任。

[原始依据](https://www.court.gov.cn/zixun/xiangqing/511101.html)

> 人工智能生成内容侵害他人著作权的，人民法院应当综合考量人工智能服务类型、行业特点、训练数据来源、各方参与度、采取的必要措施以及获利情况等因素，依法合理认定人工智能开发者、提供者、使用者的责任。
