## 03 · 计算机操作 Agent 基准提出同时比较任务成功率、耗时和成本

编号：2026-10-01-03｜原文日期：2026-09-30｜24 小时内｜arXiv 预印本

《cua-speedrun》预印本提出标准化虚拟机环境与统一 Agent 接口，在四项计算机操作基准中比较推理强度、Agent harness 和环境延迟对表现、速度及成本的影响。作者报告没有一个模型家族在三项指标上同时最优，且部分场景的更高推理强度反而缩短完成时间。

**产品经理视角：**为桌面或浏览器 Agent 选型时，单次回答速度不能代表完成一个业务流程的耗时。产品团队可固定任务集、环境和中断规则，同时记录成功率、全程时长、重试、人工接管与费用，按目标人群的真实流程形成选型表。

**可写角度：**为什么最快的模型未必能最快完成任务：计算机操作 Agent 的三维评测方法

**核验边界：**arXiv v1 于 2026-09-30T17:48:06Z 首次提交，即北京时间 10 月 1 日 01:48:06，处于严格窗口。该论文为尚未经同行评审的预印本；结果取决于作者的基准任务、虚拟机、harness 与延迟设置，不能直接外推所有生产环境。

[阅读原文](https://arxiv.org/abs/2609.40284)

> Across four different CUA benchmarks, we evaluate how reasoning effort, agent harnesses, and environment latency affect performance, speed, and cost. We find no single model family is optimal for all three.

## 04 · 预印本警示：多 Agent 即使单体安全，潜在通信链路仍可能引入新风险

编号：2026-10-01-04｜原文日期：2026-09-30｜24 小时内｜arXiv 预印本

《Safety of Latent Communication in Multi-Agent Systems》研究让 Agent 以隐藏的内部表示而非自然语言交换信息的链路。作者报告，即使组成系统的单个 Agent 保持原有安全对齐，链路训练也可能提高有害请求服从程度；在其测试的通信拓扑和安全基准中，一种攻击使平均分数从 27.9 升至 76.9。

**产品经理视角：**多 Agent 产品不能只评估单个模型的拒答表现。引入模型间消息、共享记忆或不可读的潜在表示时，团队需要把连接方式、训练数据、权限传播和系统级红队任务列为单独验收对象，并保留对关键动作的外部审计点。

**可写角度：**多 Agent 系统的安全边界为什么在模型之间：从链路训练到系统级验收

**核验边界：**arXiv v1 于 2026-09-30T14:09:57Z 首次提交，即北京时间 22:09:57，处于严格窗口。该结果来自未经同行评审的预印本，是作者实验设置下的报告；27.9 和 76.9 是所用基准的平均分数，不能解释成真实业务危害发生率。

[阅读原文](https://arxiv.org/abs/2609.39788)
